# 4.8 FinanceRepository.java



Finance access must be role- and ownership-checked. Overall finance is an administrative capability; organizers should see only permitted event finance.

```java
public interface FinanceRepository { boolean saveExpense(Expense expense); boolean saveOrganizerPayment(OrganizerPayment payment); LinkedList<Expense> getExpensesByEvent(int eventId); LinkedList<OrganizerPayment> getPaymentsByOrganizer(int organizerId); }
```
