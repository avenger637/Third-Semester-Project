# 4.5 UserRepository.java



`authenticate` should retrieve the stored password hash and verify it with a password-hashing library. Never compare or store plaintext passwords.

```java
public interface UserRepository extends Repository<User,Integer> { User findByEmail(String email); User authenticate(String email,String password); LinkedList<Organizer> getAllOrganizers(); LinkedList<Participant> getAllParticipants(); }
```
