# 5.11 GraphEdge.java



Represents an edge to another graph node, optionally with a weight.

```java
public class GraphEdge<T> { private GraphNode<T> destination; private double weight; public GraphEdge(GraphNode<T> destination,double weight){if(destination==null||!Double.isFinite(weight)||weight<0)throw new IllegalArgumentException("Invalid edge");this.destination=destination;this.weight=weight;} public GraphNode<T> getDestination(){return destination;} public double getWeight(){return weight;} }
```
