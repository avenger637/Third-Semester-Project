# 5.7 PriorityQueue.java



A priority queue delegates ordering to the heap and comparator. It can prioritize requests or scheduled activities.

```java
import java.util.Comparator;
public class PriorityQueue<T> { private Heap<T> heap; public PriorityQueue(Comparator<T> comparator){heap=new Heap<>(16,comparator);} public void enqueue(T item){heap.insert(item);} public T dequeue(){return heap.extractRoot();} public T peek(){return heap.peek();} public boolean isEmpty(){return heap.isEmpty();} public int size(){return heap.size();} }
```
