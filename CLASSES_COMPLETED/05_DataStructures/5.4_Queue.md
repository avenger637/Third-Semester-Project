# 5.4 Queue.java



Use FIFO behavior for pending item requests or other sequential processing.

```java
import java.util.NoSuchElementException;
public class Queue<T> { private LinkedList<T> list=new LinkedList<>(); public Queue(){ } public void enqueue(T data){if(data==null)throw new IllegalArgumentException("Null values are not accepted");list.addLast(data);} public T dequeue(){if(isEmpty())throw new NoSuchElementException("Queue is empty");return list.removeFirst();} public T front(){if(isEmpty())throw new NoSuchElementException("Queue is empty");return list.getFirst();} public boolean isEmpty(){return list.isEmpty();} public int size(){return list.size();} }
```
