# 5.10 GraphNode.java



Stores a graph vertex and its adjacency list.

```java
public class GraphNode<T> { private T data; private LinkedList<GraphEdge<T>> edges=new LinkedList<>(); public GraphNode(T data){if(data==null)throw new IllegalArgumentException("Data required");this.data=data;} public T getData(){return data;} public LinkedList<GraphEdge<T>> getEdges(){return edges;} public void addEdge(GraphNode<T> destination){addEdge(destination,1.0);} public void addEdge(GraphNode<T> destination,double weight){if(destination==null)throw new IllegalArgumentException("Destination required");edges.addLast(new GraphEdge<>(destination,weight));} }
```
