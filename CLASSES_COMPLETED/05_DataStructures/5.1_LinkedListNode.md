# 5.1 LinkedListNode.java



A node stores one element and a reference to the next node.

```java
public class LinkedListNode<T> {
    private T data; private LinkedListNode<T> next;
    public LinkedListNode(T data){this.data=data;} public T getData(){return data;} public LinkedListNode<T> getNext(){return next;} public void setNext(LinkedListNode<T> next){this.next=next;}
}
```
