# 6.6 GraphAlgorithms.java



BFS and DFS use a visited set to avoid revisiting vertices. With adjacency lists, both run in O(V + E).

```java
public class GraphAlgorithms {
 public static <T> void breadthFirstSearch(Graph<T> graph,T start){LinkedList<T> visited=graph==null?null:graph.bfs(start);}
 public static <T> void depthFirstSearch(Graph<T> graph,T start){LinkedList<T> visited=graph==null?null:graph.dfs(start);}
 public static <T> boolean hasPath(Graph<T> graph,T source,T destination){return graph!=null&&graph.hasPath(source,destination);}
}
```
