# 7.2 AuthorizationService.java

## Methods
- `hasRole(User user, UserRole role)`
- `isAdmin(User user)`
- `isOrganizer(User user)`
- `isParticipant(User user)`
- `canManageEvent(User user, Event event)`
- `canViewEvent(User user, Event event)`
- `canViewParticipant(User user, Participant participant)`
- `canManageFinance(User user)`
- `requireRole(User user, UserRole role)`
- `requireEventAccess(User user, Event event)`

Fail closed: deny access when identity, role, or ownership cannot be verified.

```java
public class AuthorizationService { private final AccessControl access=new AccessControl(); public boolean hasRole(User u,UserRole r){return access.checkRole(u,r);} public boolean isAdmin(User u){return hasRole(u,UserRole.ADMIN);} public boolean isOrganizer(User u){return hasRole(u,UserRole.ORGANIZER);} public boolean isParticipant(User u){return hasRole(u,UserRole.PARTICIPANT);} public boolean canManageEvent(User u,Event e){return access.canModifyEvent(u,e);} public boolean canViewEvent(User u,Event e){return u!=null&&u.isActive()&&e!=null;} public boolean canViewParticipant(User u,Participant p){return u!=null&&p!=null&&u.isActive()&&(isAdmin(u)||isOrganizer(u)||u.getUserId()==p.getUserId());} public boolean canManageFinance(User u){return access.canViewFinance(u);} public void requireRole(User u,UserRole r){if(!hasRole(u,r))throw new AuthorizationException("Required role is missing");} public void requireEventAccess(User u,Event e){if(!canViewEvent(u,e))throw new AuthorizationException("Event access denied");} }
```
