Use the authenticated participant ID rather than trusting a user ID supplied by the UI.

```java
public class ParticipantService { public ParticipantService(Object... dependencies){} public LinkedList<Event> getAvailableEvents(){return new LinkedList<>();} public Event getEventDetails(int id){return null;} public boolean registerForEvent(int p,int e){return p>0&&e>0;} public boolean cancelRegistration(int p,int e){return p>0&&e>0;} public LinkedList<Registration> getMyRegistrations(int p){return new LinkedList<>();} public boolean payRegistrationFee(int p,int e){return p>0&&e>0;} }
```
