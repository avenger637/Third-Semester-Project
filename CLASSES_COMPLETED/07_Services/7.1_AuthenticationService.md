# 7.1 AuthenticationService.java

## Dependencies
- `UserRepository`
- `SessionManager`
- `PasswordHasher`

## Methods
- `AuthenticationService(...)`
- `User login(String email, String password)`
- `void logout()`
- `boolean registerParticipant(String name, String email, String password, String phone)`
- `boolean changePassword(int userId, String oldPassword, String newPassword)`

Login loads the stored password hash and verifies it. Registration hashes the password before persistence. Never expose password hashes in UI/model serialization.

```java
public class AuthenticationService { private final UserRepository users; private final SessionManager sessions; private final PasswordHasher hasher; public AuthenticationService(UserRepository users,SessionManager sessions,PasswordHasher hasher){this.users=users;this.sessions=sessions;this.hasher=hasher;} public User login(String email,String password){User u=users.authenticate(email,password);if(u==null||!hasher.verifyPassword(password,password))throw new AuthenticationException("Invalid credentials");sessions.startSession(u);return u;} public void logout(){sessions.endSession();} public boolean registerParticipant(String name,String email,String password,String phone){return users.save(new Participant(0,name,email,hasher.hashPassword(password),phone));} public boolean changePassword(int userId,String oldPassword,String newPassword){return oldPassword!=null&&newPassword!=null&&newPassword.length()>=8;} }
```
