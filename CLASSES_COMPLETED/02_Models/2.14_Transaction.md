# 2.14 Transaction.java

Represents a financial record, such as registration income, event expenditure, or organizer payment.

## Fields
- `int transactionId`
- `int eventId` (nullable where not event-specific)
- `int userId` (associated user)
- `TransactionType type`
- `BigDecimal amount`
- `LocalDateTime transactionDate`
- `PaymentStatus status`

## Constructor
`Transaction(int transactionId, int eventId, int userId, TransactionType type, BigDecimal amount)`

## Methods
- `getTransactionId()`
- `getEventId()`
- `getUserId()`
- `getType()`
- `getAmount()`
- `getTransactionDate()`
- `getStatus()`
- `setStatus(PaymentStatus status)`

## Notes
Keep transaction history immutable where possible; corrections should be represented by reversal/refund records rather than silently editing historical amounts.

```java
import java.time.LocalDateTime;
import java.util.Locale;
public class Transaction {
 private int transactionId,eventId,userId; private TransactionType type; private BigDecimal amount; private LocalDateTime transactionDate=LocalDateTime.now(); private PaymentStatus status=PaymentStatus.PENDING;
 public Transaction(int transactionId,int eventId,int userId,TransactionType type,BigDecimal amount){if(type==null||amount==null||amount.signum()<0)throw new IllegalArgumentException("Invalid transaction");this.transactionId=transactionId;this.eventId=eventId;this.userId=userId;this.type=type;this.amount=amount;}
 public int getTransactionId(){return transactionId;} public int getEventId(){return eventId;} public int getUserId(){return userId;} public TransactionType getType(){return type;} public BigDecimal getAmount(){return amount;} public LocalDateTime getTransactionDate(){return transactionDate;} public PaymentStatus getStatus(){return status;} public void setStatus(PaymentStatus status){if(status==null)throw new IllegalArgumentException("Status required");this.status=status;}
}
```
