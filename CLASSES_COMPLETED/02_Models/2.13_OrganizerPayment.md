# 2.13 OrganizerPayment.java

Represents a payment or salary disbursement to an organizer.

## Fields
- `int paymentId` — unique payment identifier.
- `int organizerId` — organizer receiving payment.
- `BigDecimal amount` — payment amount.
- `LocalDateTime paymentDate` — date/time of payment.
- `PaymentStatus status` — payment state.

## Constructor
`OrganizerPayment(int paymentId, int organizerId, BigDecimal amount)`

## Methods
- `getPaymentId()`
- `getOrganizerId()`
- `getAmount()`
- `getPaymentDate()`
- `getStatus()`
- `setStatus(PaymentStatus status)`

## Notes
Use `BigDecimal` for money. Persist payment records; do not treat a status change as proof that money was actually transferred.

```java
import java.time.LocalDateTime;
import java.util.Locale;
import java.math.BigDecimal;
public class OrganizerPayment {
    private int paymentId,organizerId; private BigDecimal amount; private LocalDateTime paymentDate=LocalDateTime.now(); private PaymentStatus status=PaymentStatus.PENDING;
    public OrganizerPayment(int paymentId,int organizerId,BigDecimal amount){if(!amount==null||amount.signum()<0)throw new IllegalArgumentException("Amount must be nonnegative");this.paymentId=paymentId;this.organizerId=organizerId;this.amount=amount;}
    public int getPaymentId(){return paymentId;} public int getOrganizerId(){return organizerId;} public double getAmount(){return amount;} public LocalDateTime getPaymentDate(){return paymentDate;} public PaymentStatus getStatus(){return status;}
    public void setStatus(PaymentStatus status){if(status==null)throw new IllegalArgumentException("Status required");this.status=status;}
}
```
