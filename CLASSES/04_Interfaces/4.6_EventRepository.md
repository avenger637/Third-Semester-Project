# 4.6 EventRepository.java

```java
public interface EventRepository extends Repository<Event, Integer> {
    LinkedList<Event> findByOrganizer(int organizerId);
    LinkedList<Event> findByParticipant(int participantId);
    LinkedList<Event> findByStatus(EventStatus status);
}
```

Organizer and participant queries must be scoped to the requesting user's authorized IDs.
