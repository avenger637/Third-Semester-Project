# 4.9 RequestRepository.java

```java
public interface RequestRepository extends Repository<ItemRequest, Integer> {
    LinkedList<ItemRequest> findByEvent(int eventId);
    LinkedList<ItemRequest> findByOrganizer(int organizerId);
    LinkedList<ItemRequest> findPendingRequests();
}
```

Pending requests can also be loaded into a Java Queue for DSA-based processing.
