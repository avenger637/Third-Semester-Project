# 6.1 SearchingAlgorithms.java

```java
public class SearchingAlgorithms {
    public static <T> int linearSearch(
        T[] array, T target, Comparator<T> comparator);

    public static <T> int binarySearch(
        T[] array, T target, Comparator<T> comparator);

    public static <T> T searchById(
        LinkedList<T> list, int id, ToIntFunction<T> idExtractor);

    public static <T> T searchByName(
        LinkedList<T> list, String name,
        Function<T, String> nameExtractor);
}
```

Linear search: O(n). Binary search: O(log n), but requires sorted input.
