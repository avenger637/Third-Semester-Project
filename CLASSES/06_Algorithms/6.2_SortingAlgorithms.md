# 6.2 SortingAlgorithms.java

```java
public class SortingAlgorithms {
    public static <T> void mergeSort(T[] array, Comparator<T> comparator);
    public static <T> void quickSort(T[] array, Comparator<T> comparator);
    public static <T> void heapSort(T[] array, Comparator<T> comparator);
    public static <T> void insertionSort(T[] array, Comparator<T> comparator);
    public static <T> void bubbleSort(T[] array, Comparator<T> comparator);
}
```

Suggested use: sort events by date, participants by name, and expenses by amount. Merge sort is O(n log n); quicksort averages O(n log n) but can be O(n²) in the worst case.
