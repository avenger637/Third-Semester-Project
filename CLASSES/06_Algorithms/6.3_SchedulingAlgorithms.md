# 6.3 SchedulingAlgorithms.java

```java
public class SchedulingAlgorithms {
    public static void sortSchedule(LinkedList<ScheduleItem> schedule);
    public static boolean detectConflict(ScheduleItem first, ScheduleItem second);
    public static boolean detectAnyConflict(LinkedList<ScheduleItem> schedule);
    public static LinkedList<ScheduleItem> getSortedSchedule(
        LinkedList<ScheduleItem> schedule);
    public static ScheduleItem getNextActivity(
        LinkedList<ScheduleItem> schedule, LocalDateTime currentTime);
}
```

Conflict rule for half-open time intervals: two activities overlap if `start1 < end2 && start2 < end1`. Validate start before end.
