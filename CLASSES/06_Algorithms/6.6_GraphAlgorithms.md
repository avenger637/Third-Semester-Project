# 6.6 GraphAlgorithms.java

```java
public class GraphAlgorithms {
    public static <T> void breadthFirstSearch(Graph<T> graph, T start);
    public static <T> void depthFirstSearch(Graph<T> graph, T start);
    public static <T> boolean hasPath(
        Graph<T> graph, T source, T destination);
}
```

BFS and DFS use a visited set to avoid revisiting vertices. With adjacency lists, both run in O(V + E).
