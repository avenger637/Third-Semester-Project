# 6.4 BudgetAlgorithms.java

```java
public class BudgetAlgorithms {
    public static BigDecimal calculateTotalExpenses(LinkedList<Expense> expenses);
    public static BigDecimal calculateRemainingBudget(
        BigDecimal allocated, BigDecimal spent);
    public static BigDecimal calculateUtilization(
        BigDecimal allocated, BigDecimal spent);
    public static boolean checkBudgetLimit(
        BigDecimal allocated, BigDecimal spent, BigDecimal newExpense);
    public static LinkedList<Expense> sortExpenses(
        LinkedList<Expense> expenses);
    public static Expense findLargestExpense(LinkedList<Expense> expenses);
}
```

Use `BigDecimal`, reject negative values, and ensure budget checks and expense persistence occur consistently in a transaction.
