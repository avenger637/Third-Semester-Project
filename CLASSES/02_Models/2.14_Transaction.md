# 2.14 Transaction.java

Represents a financial record, such as registration income, event expenditure, or organizer payment.

## Fields
- `int transactionId`
- `int eventId` (nullable where not event-specific)
- `int userId` (associated user)
- `TransactionType type`
- `BigDecimal amount`
- `LocalDateTime transactionDate`
- `PaymentStatus status`

## Constructor
`Transaction(int transactionId, int eventId, int userId, TransactionType type, BigDecimal amount)`

## Methods
- `getTransactionId()`
- `getEventId()`
- `getUserId()`
- `getType()`
- `getAmount()`
- `getTransactionDate()`
- `getStatus()`
- `setStatus(PaymentStatus status)`

## Notes
Keep transaction history immutable where possible; corrections should be represented by reversal/refund records rather than silently editing historical amounts.
