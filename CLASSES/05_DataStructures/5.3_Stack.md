# 5.3 Stack.java

```java
public class Stack<T> {
    private LinkedList<T> list;

    public Stack();
    public void push(T data);
    public T pop();
    public T peek();
    public boolean isEmpty();
    public int size();
}
```

Use LIFO behavior for a meaningful feature such as undo history. `pop` and `peek` should handle an empty stack safely (exception or documented sentinel).
