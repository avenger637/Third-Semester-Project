# 5.7 PriorityQueue.java

```java
public class PriorityQueue<T> {
    private Heap<T> heap;

    public PriorityQueue(Comparator<T> comparator);
    public void enqueue(T item);
    public T dequeue();
    public T peek();
    public boolean isEmpty();
    public int size();
}
```

A priority queue delegates ordering to the heap and comparator. It can prioritize requests or scheduled activities.
